# Ley 2398-L: Se adhiere la Provincia de San Juan a la Ley Nacional N° 27592 denominada "Ley Yolanda", la cual tiene por objeto garantizar la formación integral en perspectiva de desarrollo sostenible para las personas que se desempeñen en la función pública.
