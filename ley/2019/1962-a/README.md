# Ley 1962-A: Se declaran de utilidad pública y sujetos a expropiación, conforme a la Ley General de Expropiaciones Nº 1000-A, inmuebles ubicados en el Departamento Caucete, con el objeto de ser  destinados a la creación de  una zona de reserva paleontológica y turística.
