# Ley 1961-Q: Se establece la obligatoriedad de incluir la leyenda “el consumo de alcohol en exceso es perjudicial para la salud” en todas las entradas y tickets de espectáculos públicos y privados autorizados para el expendio y comercialización de bebidas alcohólicas en la Provincia de San Juan.
