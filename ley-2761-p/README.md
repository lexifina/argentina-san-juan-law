# Ley 2761-P: Se instituye el 15 noviembre de cada año, como el DÍA PROVINCIAL DE LA CONCIENTIZACIÓN DE LA HIPERTENSIÓN PULMONAR (HAP), con el fin de crear conciencia e informar a la población acerca de esta enfermedad.
